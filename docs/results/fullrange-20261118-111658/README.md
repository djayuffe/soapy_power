# fullrange-20261118-111658

Full 70 MHz–6 GHz scan of the B200mini receive chain with an antenna on RX2,
20 dB gain, and two 300 s variants: all analysis features ON (telemetry, RF
state, headroom, coverage) and OFF (for the ON/OFF effects comparison).

**Evidence level: hardware-observed, relative and uncalibrated.** The input was
an antenna, not a controlled 50 Ω load, so both variants include external RF
changes. Nothing here is dBm, noise figure, an absolute floor, or traceable
calibration.

- Session: `sessions/fullrange-20261118-111658` (gitignored; ~2.1 GB raw JSONL)
- Session ran 2026-11-18 11:16–11:28 UTC
- Software: repo `8949ddd` (`v1.6.1-63-g8949ddd`), scan code `155e1ad`,
  SoapySDR 0.8.1, UHD 4.10/4.11
- Device: B200mini serial `30B2A32`, `driver=uhd,type=b200`, internal clock
- Plan: 70 MHz–6 GHz, 56 MHz capture per record, 1 MHz comparison cells
- ON plan: mask-aware coverage (`--ensure-coverage`), 215 centers at ~27.98 MHz
  spacing
- OFF plan: default hop plan, 849 centers at 6.986 MHz spacing
- Command: `tools/macos_runner/queue.sh scan --seconds 300 --gain 20
  --antenna RX2 --input antenna --procedure fullrange --wait 2400`

Each 215-center ON sweep is a complete pass; OFF completes 8.32 passes of its
849-center sweep in the same wall time. The plans are not identical: ON uses the
mask-aware coverage planner (215 centers, ~27.98 MHz steps), while OFF runs the
default hop plan (849 centers, 6.986 MHz steps). Both cover 70–6000 MHz, but hop
density and time sampling differ, so record rate and pass count are not a
like-for-like throughput comparison. The ON/OFF cell comparison uses all common
1 MHz cells across those differing numbers of passes.

ON/OFF agreement over 5,929 common cells:

- Median Δ (ON − OFF): −0.0425 dB
- Robust σ: 0.3155 dB
- p95 |Δ|: 0.7599 dB
- Cells with |Δ| > 3 dB: 48

The median offset is below 0.05 dB. The tail is expected because the antenna
sees a changing RF environment between the two variants.

## 150–160 MHz

The band remains the clearest unresolved feature:

- ON per-pass median range: **18.78 dB** (−133.63 to −114.85 dB) over 24 passes.
- OFF per-pass median: −131.17 dB, from 9 passes.
- The swing reproduces the previous full-range run (≈16 dB), so it is not a
  one-off.
- It is **not** attributed to the receiver, the spur model, or an external
  source. Resolving it requires a controlled 50 Ω input and/or an alternating
  ON/OFF source run. No notch, exclusion, or correction is applied.

## Reproduce

```sh
tools/macos_runner/queue.sh scan --seconds 300 --gain 20 --antenna RX2 \
    --input antenna --procedure fullrange --wait 2400

# after the runner has written compare.json / waterfall.json:
env -u PYTHONPATH sessions/.venv/bin/python tools/fullrange_telemetry.py \
    sessions/fullrange-<stamp>
env -u PYTHONPATH sessions/.venv/bin/python tools/report_hero.py \
    sessions/fullrange-<stamp>
```

The runner generates `compare.json`, `waterfall.json`, the 3D waterfalls,
`intermittent.png` and `report.pdf` automatically. Raw JSONL stays in
`sessions/` and is not committed.

## Limits

- Antenna input: external signals and interference are part of the series.
- Two 300 s variants only; not a soak test. 600 s per-trial behaviour remains
  unverified.
- Single device, single gain, RX2, one antenna.
- The RFIC temperature sensor is coarsely quantised; no thermal coefficient is
  claimed.
- 150–160 MHz cause unresolved; controlled 50 Ω / alternating ON/OFF work is
  still required.
